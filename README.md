## Find-All-Solutions-with-Dynamic-Adjustment-25
This repository contains sample files for a system designed to find all solutions in a search space using Grover's algorithm and dynamic updates of estimated solution count. The table below provides an overview of the available files.

### Sample Codes
|     File Name       |     Description                               |
| ------------------- | --------------------------------------------- |
| OOO.py | This script demonstrates methods for finding all solutions using Grover's algorithm and dynamic adjustment, implemented with a custom, streamlined simulator. |
| OOO.py | This script demonstrates methods for finding all solutions using Grover's algorithm and dynamic adjustment, implemented with the Qiskit library. |
