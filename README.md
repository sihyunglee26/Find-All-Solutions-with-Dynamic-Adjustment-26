## Find-All-Solutions-with-Dynamic-Adjustment-26
This repository contains sample files for a system designed to find all solutions in a search space using Grover's algorithm and dynamic updates of estimated solution count. The table below provides an overview of the available files.

### Sample Codes
|     File Name       |     Description                               |
| ------------------- | --------------------------------------------- |
| [v2_dynamic_update_with_custom_simulator.py](https://github.com/sihyunglee26/Find-All-Solutions-with-Dynamic-Adjustment-26/blob/main/v2_dynamic_update_with_custom_simulator.py) | This script demonstrates methods for finding all solutions using Grover's algorithm and dynamic adjustment, implemented with a **custom, streamlined simulator**. |
| [v2_dynamic_update_with_Qiskit.py](https://github.com/sihyunglee26/Find-All-Solutions-with-Dynamic-Adjustment-26/blob/main/v2_dynamic_update_with_Qiskit.py) | This script demonstrates methods for finding all solutions using Grover's algorithm and dynamic adjustment, implemented with **the Qiskit library**. |
| [simulation_dynamic_adjustment.log](https://github.com/sihyunglee26/Find-All-Solutions-with-Dynamic-Adjustment-26/blob/main/simulation_dynamic_adjustment.log) | This is a sample log file generated by v2_dynamic_update_with_custom_simulator.py. |
